# Do I need to live in Argentina full-time?

No. You do not need to live in Argentina full-time under the proposed program as currently anticipated. No residence or physical-presence requirement is currently anticipated to maintain status. That has not been officially confirmed.

Ordinary two-year Argentine naturalization is a different track. It is not this program. For how status is expected to be maintained more broadly, see [how to maintain Argentina residency](/faq/maintain-argentina-residency).
