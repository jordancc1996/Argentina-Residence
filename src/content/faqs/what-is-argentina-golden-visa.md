# What is the Argentina Golden Visa program?

The Argentina Golden Visa is an investment-based residency program that allows foreign nationals to obtain temporary residency by making qualifying investments in Argentina. The [Argentina Golden Visa program](/guides/argentina-golden-visa-program) guide states the current framework and that APCI is not processing applications.
